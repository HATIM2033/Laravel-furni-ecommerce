🛒 Laravel 12 E-Commerce Platform

A modern, full-featured E-Commerce web application built with Laravel 12, designed to provide a smooth shopping experience for users and a powerful management dashboard for administrators.

This project focuses on clean architecture, performance, usability, and scalability.

🚀 Features
👤 User Features

Modern Home Page with featured products

Shop Page with product listing

Product Details Page

Smart Shopping Cart with:

Dynamic quantity updates

Live cart badge counter

Real-time total calculation

Secure Authentication System (Login & Register)

User Profile Management

Order History & Tracking

Contact Form with admin reply system

Responsive design (Mobile / Tablet / Desktop)

🛠️ Admin Dashboard Features

Advanced Admin Dashboard

Full Product Management (Create, Edit, Delete, Activate, Deactivate, Featured)

Category Management

User Management

Order Management & Status Tracking

Contact Messages Management

Real-Time Notifications System

Global statistics overview

🧰 Tech Stack

Backend: Laravel 12

Frontend: Blade + Bootstrap 5 + JavaScript

Database: MySQL

Authentication: Laravel Breeze

Architecture: MVC Pattern

⚙️ Installation Guide
git clone https://github.com/your-username/laravel12-ecommerce.git
cd laravel12-ecommerce
composer install
npm install && npm run dev
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve


Then open:

👉 http://127.0.0.1:8000

## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.
